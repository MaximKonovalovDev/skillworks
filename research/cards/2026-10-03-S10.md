## Pipeline truth (chapter chunk + on-demand index, not fixed chunks)

- Donor compiles once: extract → `full_text.txt` + `metadata.json` (per-source
  sha256, token counts) → agent structural analysis (Step 3: chapters from
  headings/ToC) → per-chapter files `chapters/ch<NN>-<slug>.md` with
  BOOK_TYPE×DEPTH token budgets → master SKILL.md (cap 4000 tokens, core
  frameworks ~2000 + chapter/topic index) → `glossary.md`/`patterns.md`/
  `cheatsheet.md`. Resident cost = small SKILL.md core + one chapter on
  demand; discovery_tax.py models context-dump vs discovery-best/loop vs
  skill to prove 24–51x savings.
- Ours splits blind (5k chars + 200 overlap, no headings) and indexes head
  snippets only (file+chars+head, substring count). Gap: no chapter
  boundaries, no budgets, no cost model, no fingerprint-guarded reuse.
