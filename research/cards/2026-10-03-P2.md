## Serving truth (what the best do that we do not)

- `aigengame/godot-agent` (MIT, live): one operation surface, three access
  paths — CLI (`gda <group> <command> --json`) + bundled Agent Skill
  (`gda skill` → SKILL.md) + MCP server (`gda-mcp` stdio). Server is
  *generated*: startup `gda schema` dump → one MCP tool per command
  (`<group>_<command>`, description ← help, input/output schemas ← command
  models), single verbatim dispatcher (`gda <group> <command> --params-json -`
  on stdin, `--json` result). Success → `structured_content` + JSON
  `TextContent` block; failure → `is_error=True` with full `GdaError`
  envelope verbatim, never flattened. Serves both protocol eras, roots
  back-channel with `GDA_PROJECT` pin, `tools/list` cache hint 1h.
  Reference: `https://github.com/aigengame/godot-agent/blob/main/src/gda/mcp/server.py`.
- `NousResearch/hermes-agent` (MIT, live): client-side counterpart —
  persistent per-server tasks on one background loop, paginated `list_*`
  discovery (50-page cap, SEP-2549 cache hints), circuit breaker (3 strikes /
  60s cooldown), trust-tier gating, plus progressive-disclosure skills:
  `skills_list` (name+description only) → `skill_view(name, file_path?)`
  (full SKILL.md + linked `references/templates/assets/scripts`, collision
  refusal, quarantine gate, path-traversal reject). Our server is the mirror
  image: search-only, no list/view split, no pagination, no breaker.
- `modelcontextprotocol/python-sdk` (MIT, live): stdio transport hygiene our
  78-line server skips — fd 0/1 claim table (second `stdio_server()` raises),
  private dup above std range, divert stdin→/dev/null + stdout→stderr while
  serving, UTF-8 rewrap, restore on exit. Our `server.py` reads
  `sys.stdin` / writes `sys.stdout` directly with no claim, no divert, no
  restore.
