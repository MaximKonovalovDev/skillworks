## Market truth (where is the domain gap?)

- Index: SkillsGate Discover is powered by skills.sh, an open directory of
  agent skills; the app reads the catalog and fetches each skill straight from
  its GitHub repo (skillsgate.ai FAQ, live). Trending arrives ranked by install
  count (`fetchTrending`/`parseTrending` over `https://www.skills.sh/trending`,
  page order = install-count descending, ideas only).
- Preview-then-install: Discover shows full SKILL.md + install count + source
  repo before install ("How it works": Search → Preview → Install → Edit).
- Serving shape: 19-agent registry (`agentRegistry` in ipc-handlers.ts) with
  per-agent skill control + universal `~/.agents/skills` shared dir; canonical
  skill store with symlink-per-agent install (`installSkillToAgent`:
  copy-to-canonical then symlink, copy fallback); provenance lock
  `~/.agents/.skill-lock.json` {version, source, sourceType, installedAt,
  updatedAt}; single-flight rescan + fingerprint cache + single-skill
  incremental rescan (`rescanSingleSkill`) + file watcher.
- Domain gap (R4): the catalog, trending-by-installs, and 19 coding-agent
  targets are all dev-wrapper shaped — installs concentrate on coding skills,
  and discovery has no domain lane. Our edge: owned-book domain packs
  (psychology + programming seeds) served through the same SKILL.md-bundle
  shape, ranked by eval gate instead of installs.
