# VISION: skillworks (2026-10-03)

skillworks turns books into Agent Skills. Maxim: "SKILLS BOOKS IS GOLD IDEA". Psychology and programming books go in; a tested skill and an MCP server come out. It is also where his skills get better over time: the best improved skill is adopted by the other 8 repos, so every loop gets smarter. Finished = one skill adopted by 5 of the 9 repos and the first tested pack for sale. Owned or public-domain books only; repo public, no secrets.

Direction 2026-10-03 (Maxim): skillworks is the trainer of the fleet. It turns licensed manuals (PowerShell-Docs, Pro Git, Playwright, Bevy) into tested skills that fix the mistakes the loops measurably make every day (bash typed into pwsh, git clashes, wrong browser drivers, Bevy misuse), one command: `python -m book2skill make`. Those skills, adopted by other repos, are work number one (finish bars S1, S2). The psychology and git packs are the product line for the shop (K-44), not feed for the loops.
