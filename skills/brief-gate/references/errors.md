# Error lines the pairs replay (all thrown live by scripts/run_brief.py in pwsh 7)

Each fragment below is a substring of the real `bad_text` of the named pair. The good side of the same pair prints the gated brief report instead.

- `dispatched with no brief on disk`: dispatch with no brief written. Pair `bg-write`
- `started with no brief to gate on`: dispatch with no gate. Pair `bg-gate`
- `one-line brief sent the pilot at the wrong file`: vague one-line brief. Pair `bg-sections`
- `assumed brief present before dispatch`: assumed brief, never checked. Pair `bg-verify`
- `oral handoff left the pilot reading missing files`: oral handoff, nothing written. Pair `bg-handoff`
- `skipped approval on stale paths`: dispatch skipped approval. Pair `bg-approval`
- `pilot opened with no written plan`: pilot opened with no plan. Pair `bg-plan`
- `build requested with no brief file`: build with no brief file. Pair `bg-build`
- `handoff arrived with no shaped sections`: handoff with no sections. Pair `bg-shape`
- `queued dispatch read before any check`: dispatch queued with no check. Pair `bg-check`
- `cross-repo task opened with no brief file`: cross-repo task with no brief. Pair `bg-file`
- `second wave planned with no approved brief`: second wave with no approval. Pair `bg-result`
