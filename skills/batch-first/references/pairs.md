# Tested pairs: timeouts and the batch-first fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the GitHub timeout line. `good` prints the answer shown.

## Batch the reads first

### bf-batch
bad (throws: Request timed out):
```
throw 'Request timed out after scattered GitHub calls in owner/name'
```
good:
```
$s = Get-Content -LiteralPath record.txt -Raw; Start-Sleep -Milliseconds 100; 'batch timeout PASS capped'
```
prints: `batch timeout PASS capped`
