# Tested pairs: timeouts and the one-retry fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the webfetch timeout line. `good` prints the answer shown.

## Retry once after a timeout

### wf-retry
bad (throws: Request timed out):
```
throw 'Request timed out after 30000ms fetching slow page <url>'
```
good:
```
$u = Get-Content -LiteralPath url.txt -Raw; Start-Sleep -Milliseconds 100; 'retry backoff narrower PASS once'
```
prints: `retry backoff narrower PASS once`
