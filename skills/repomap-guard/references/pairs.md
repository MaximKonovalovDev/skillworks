# Tested pairs: missing map reads and the list-first fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the missing-map line. `good` prints the answer shown.

## List before any map read

### rm-list
bad (throws: File not found:
```
throw 'File not found: owner/name/.opencode/repomap.md blind read'
```
good:
```
$l = Get-ChildItem -Name; "list folder PASS checked once: $($l -join ', ')"
```
prints: `list folder PASS checked once`

### rm-glob
bad (throws: File not found:
```
throw 'File not found: owner/name/other/repomap.md guessed path'
```
good:
```
$h = Get-ChildItem -Recurse -Filter repomap.md; 'glob check PASS no guess'
```
prints: `glob check PASS no guess`

### rm-single
