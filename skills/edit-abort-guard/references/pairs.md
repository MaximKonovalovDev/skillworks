# Tested pairs: edit aborts and the slice-to-one-hunk fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the edit-abort line. `good` lands its hunk and prints the answer shown.

## Slice every edit

### ea-slice
bad (throws: Tool execution aborted:
```
throw 'Tool execution aborted: unbounded whole-file edit in one call'
```
good:
```
$l = Get-Content -LiteralPath big.txt; $l[2] = 'line 03 edit hunk fixed'; Set-Content -LiteralPath big.txt -Value $l; 'slice hunk PASS small window'
```
prints: `slice hunk PASS small window`

