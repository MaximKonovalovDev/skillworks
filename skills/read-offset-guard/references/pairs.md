# Tested pairs: past-the-end reads and the count-first clamp fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the Offset out of range line. `good` prints the answer shown.

## Count the lines first

### ro-count
bad (throws: Offset .* is out of range):
```
throw 'Offset 100 is out of range for this file (50 lines) on a stale count'
```
good:
```
$n = @(Get-Content -LiteralPath target.txt).Count; $o = [Math]::Max(0, [Math]::Min(100, $n - 1)); "count $n clamp offset $o lines PASS counted"
```
prints: `count 7 clamp offset 6 lines PASS counted`

### ro-stale
bad (throws: Offset .* is out of range):
```
throw 'Offset 600 is out of range for this file (470 lines) from a stale length'
```
good:
```
$n = @(Get-Content -LiteralPath target.txt).Count; $o = [Math]::Max(0, [Math]::Min(600, $n - 1)); "length $n clamp offset $o step PASS recounted"
```
prints: `length 7 clamp offset 6 step PASS recounted`

### ro-past-end
bad (throws: Offset .* is out of range):
```
throw 'Offset 28 is out of range for this file (27 lines) one past the end'
```
good:
```
$n = @(Get-Content -LiteralPath target.txt).Count; $t = @(Get-Content -LiteralPath target.txt -Tail 2); "tail clamp offset $n lines $($t.Count) PASS tailed"
```
prints: `tail clamp offset 7 lines 2 PASS tailed`

### ro-overshoot
bad (throws: Offset .* is out of range):
```
throw 'Offset 88 is out of range for this file (45 lines) with limit 10 overshoot'
```
good:
```
$n = @(Get-Content -LiteralPath target.txt).Count; $o = [Math]::Max(0, [Math]::Min(88, $n - 1)); $l = [Math]::Min(10, $n - $o); "clamp limit offset $o lines $l PASS shrunk"
```
prints: `clamp limit offset 6 lines 1 PASS shrunk`

## Clamp every offset and step

### ro-jump
bad (throws: Offset .* is out of range):
```
throw 'Offset 170 is out of range for this file (31 lines) on a blind jump'
```
good:
```
$h = @(Get-Content -LiteralPath target.txt -TotalCount 3); "head step offset 0 lines $($h.Count) PASS walked-head"
```
prints: `head step offset 0 lines 3 PASS walked-head`

good:
```
$n = @(Get-Content -LiteralPath target.txt).Count; "length $n clamp offset 6 limit 3 PASS limited"
```

### ro-head
bad (throws: Offset .* is out of range):
```
throw 'Offset 40 is out of range for this file (7 lines) on a guessed section'
```
good:
```
$sec = @(Get-Content -LiteralPath target.txt | Select-Object -Skip 0 -First 3); "length offset 0 limit 3 PASS section-lines $($sec.Count)"
```
prints: `length offset 0 limit 3 PASS section-lines 3`

## Tail the end and report

### ro-walk
bad (throws: Offset .* is out of range):
```
throw 'Offset 90 is out of range for this file (7 lines) walking past the end'
```
good:
```
$o = 0; $l = 3; $a = @(Get-Content -LiteralPath target.txt | Select-Object -Skip $o -First $l); $o += $l; "step limit $l lines $($a.Count) PASS stepped-$o"
```
prints: `step limit 3 lines 3 PASS stepped-3`

### ro-tail
bad (throws: Offset .* is out of range):

```
throw 'Offset 8 is out of range for this file (7 lines) one past the end'
```
good:
```
$t = @(Get-Content -LiteralPath target.txt -Tail 2); "tail lines $($t.Count) PASS tailed-end"
```
prints: `tail lines 2 PASS tailed-end`

```
$n = @(Get-Content -LiteralPath target.txt).Count; "count offset 6 PASS recounted-$n"
```

### ro-report
bad (throws: Offset .* is out of range):
```
throw 'Offset 70 is out of range for this file (7 lines) with no result reported'
```
good:
```
Set-Content -LiteralPath report.txt -Value 'offset 6 limit 3'; "RESULT offset 6 PASS reported"
```
prints: `RESULT offset 6 PASS reported`
