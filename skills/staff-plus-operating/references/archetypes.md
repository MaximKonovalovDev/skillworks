# Archetypes (own words; idea after Will Larson, Staff Engineer 2021)

Four named ways to do senior work without a manager title. Pick one per task and stay in it until the report is filed. No text is copied from any book.

## tech-lead

Guides one team through one build. Keeps direction and delivery in one head: writes the plan, splits the work, unblocks the queue, and holds the bar. Use when the scope is `team`. Done when the team ships without waiting on you. Avoid: deciding for other teams.

## architect

Sets direction across teams. Writes the shape others build to: the bounds, the seams, and the trade-offs. Use when the scope is `multi-team`. Done when two teams can build apart and still fit. Avoid: owning one team delivery date.

## solver

Takes the single hard problem nobody else can close. Goes deep for a short time, fixes the core, then hands it back with notes. Use when the scope is `single-hard-problem`. Done when the blocker is gone and the owner can carry on. Avoid: staying on as the owner.

## right-hand

Extends one leader reach across groups. Carries context, decisions, and follow-ups so the leader does not become the bottleneck. Use when the scope is `leader-support`. Done when the groups move with the same picture. Avoid: making the call the leader must make.

Scope map (fixed, lowercase): `team` gives `tech-lead`, `multi-team` gives `architect`, `single-hard-problem` gives `solver`, `leader-support` gives `right-hand`.
