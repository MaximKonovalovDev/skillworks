# Tested pairs: the Rustacean misses and the idiomatic fixes

Made from pairs.json. Do not edit this file by hand.
Every pair runs through scripts/idiomatic_rust.py. bad replays the miss. good prints the answer shown.

## Names and flow

### ir-p01

Name cases: const type and function

bad:
```rust
const max_size: u32 = 10;
struct userId { id: u32, }
fn GetName(id: u32) -> u32 { id }
```
good:
```rust
const MAX_SIZE: u32 = 10;
struct UserId { id: u32, }
fn user_id(id: u32) -> u32 { id }
```
prints: `MAX_SIZE`

## Names and flow

### ir-p02

Option with match, never unwrap

bad:
```rust
fn get_first(v: Option<i32>) -> i32 { v.unwrap() }
```
good:
```rust
fn get_first(v: Option<i32>) -> i32 { match v { Some(n) => n, None => 0, } }
```
prints: `match`

### ir-p03

Result with question mark, never unwrap

bad:
```rust
use std::fs;
fn read_len(path: &str) -> Result<usize, std::io::Error> { let s = fs::read_to_string(path).unwrap(); Ok(s.len()) }
```
good:
```rust
use std::fs;
fn read_len(path: &str) -> Result<usize, std::io::Error> { let s = fs::read_to_string(path)?; Ok(s.len()) }
```
prints: `Result`

### ir-p04

Iterators over index loops

bad:
```rust
fn sum(v: &[i32]) -> i32 { let mut total = 0; for i in 0..v.len() { total += v[i]; } total }
```
good:
```rust
fn sum(v: &[i32]) -> i32 { v.iter().sum() }
```
prints: `iter`

## Building blocks

### ir-p05

Builder with chained with steps

bad:
```rust
struct Server { host: String, }
impl Server { fn set_host(&mut self, h: String) { self.host = h; } }
```
good:
```rust
struct Server { host: String, }
impl Server { fn with_host(mut self, h: String) -> Self { self.host = h; self } fn build(self) -> Self { self } }
```
prints: `build()`

### ir-p06

Newtype over bare String id

bad:
```rust
fn greet(id: String) -> String { format!("hi {}", id) }
```
good:
```rust
struct UserId(String);
fn greet(id: UserId) -> String { format!("hi {}", id.0) }
```
prints: `UserId`

### ir-p07

RAII Drop over manual cleanup

bad:
```rust
struct Lock { name: String, }
impl Lock { fn cleanup(&self) { println!("{}", self.name); } }
```
good:
```rust
struct Lock { name: String, }
impl Drop for Lock { fn drop(&mut self) { println!("{}", self.name); } }
```
prints: `Drop`

### ir-p08

Extension trait plus blanket bound

bad:
```rust
fn extra(s: &str) -> usize { s.len() + 1 }
```
good:
```rust
trait Ext { fn extra(&self) -> usize; }
impl Ext for str { fn extra(&self) -> usize { self.len() + 1 } }
```
prints: `trait Ext`

## Borrowing and avoidance

### ir-p09

Borrowed str over owned String ref

bad:
```rust
fn len_of(s: &String) -> usize { s.len() }
```
good:
```rust
fn len_of(s: &str) -> usize { s.len() }
```
prints: `&str`

### ir-p10

Cow for maybe owned text

bad:
```rust
fn label(name: String) -> String { let owned: String = name.clone(); format!("hi {}", owned) }
```
good:
```rust
use std::borrow::Cow;
fn label(name: Cow<'_, str>) -> String { format!("hi {}", name) }
```
prints: `Cow`

### ir-p11

Borrow in loops, never clone

bad:
```rust
fn main() { let v = vec![String::from("a")]; for item in v.clone() { println!("{}", item.clone()); } }
```
good:
```rust
fn main() { let v = vec![String::from("a")]; for item in &v { println!("{}", &item); } }
```
prints: `&item`

### ir-p12

No Deref poly, no singleton, tiny unsafe

bad:
```rust
use std::ops::Deref;
struct Wrap(String);
impl Deref for Wrap { type Target = String; fn deref(&self) -> &Self::Target { &self.0 } }
static mut COUNTER: u32 = 0;
fn main() { unsafe { COUNTER += 1; } }
```
good:
```rust
struct Wrap(String);
impl Wrap { fn get(&self) -> &str { &self.0 } }
fn main() { let w = Wrap(String::from("a")); }
```
prints: `singleton`
