# Tested pairs: keeper holds and the queue-first fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the keeper-hold line. `good` prints the answer shown.

## Check the queue first

### kr-queue
bad (throws: Keeper readiness hold:
```
throw 'Keeper readiness hold: no unclaimed ready work or changed evidence blind dispatch'
```
good:
```
$l = Get-ChildItem -Name; "queue unclaimed PASS ready listed: $($l -join ', ')"
```
prints: `queue unclaimed PASS ready listed`

### kr-single

Get-ChildItem -Name | Select-Object -First 1 | Out-Null; 'single listing PASS stopped once'
