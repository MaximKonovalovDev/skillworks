# Tested pairs: write aborts and the slice-small fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the write-abort line. `good` prints the answer shown.

## Slice every write

### wa-slice
bad (throws: Tool execution aborted:
```
throw 'Tool execution aborted: whole write in one call'
```
good:
```
Set-Content -LiteralPath chunk.txt -Value 'slice 1-5 small chunk'; 'slice chunk timeout PASS 1-5'
```
prints: `slice chunk timeout PASS 1-5`

### wa-chunk
bad (throws: Tool execution aborted:
```
throw 'Tool execution aborted: whole write of one section'
```
good:
```
Set-Content -LiteralPath section.txt -Value 'sec'; 'chunk slice timeout PASS section'
```
prints: `chunk slice timeout PASS section`

## Background long writes

### wa-back
bad (throws: Tool execution aborted:
```
throw 'Tool execution aborted: foreground wait on a long write'
```
good:
```
Set-Content -LiteralPath receipt.txt -Value 'chunk 1-5 done'; $t = 0; while (-not (Test-Path -LiteralPath receipt.txt) -and $t -lt 50) { Start-Sleep -Milliseconds 100; $t++ }; Get-Content -LiteralPath receipt.txt -Raw | Out-Null; 'background receipt timeout PASS polled'
```
prints: `background receipt timeout PASS polled`
