# Tested pairs: aborts and the repro-first fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the task abort line. `good` prints the answer shown.

## Repro the step first

bad (throws: Tool execution aborted):
```
throw 'Tool execution aborted after long foreground task call with no repro on record'
```

```

```
