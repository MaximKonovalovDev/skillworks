# Tested pairs: read aborts and the slice-small fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the read-abort line. `good` prints the answer shown.

## Slice every read

### ra-slice
bad (throws: Tool execution aborted:
```
throw 'Tool execution aborted: unbounded full read in one call'
```
good:
```
Get-Content -LiteralPath big.txt -TotalCount 5 | Out-Null; 'slice limit PASS small window'
```
prints: `slice limit PASS small window`

### ra-check
bad (throws: Tool execution aborted:
```
throw 'Tool execution aborted: full read of a section that needed a slice'
```
good:
```
Get-Content -LiteralPath notes.md -TotalCount 2 | Out-Null; 'small check PASS sliced lines'
```
prints: `small check PASS sliced lines`

## Check size, background long reads

### ra-back
bad (throws: Tool execution aborted:
```
throw 'Tool execution aborted: foreground wait on a long read'
```
good:
```
Set-Content -LiteralPath receipt.txt -Value 'slice 1-5 done'; $t = 0; while (-not (Test-Path -LiteralPath receipt.txt) -and $t -lt 50) { Start-Sleep -Milliseconds 100; $t++ }; Get-Content -LiteralPath receipt.txt -Raw | Out-Null; 'background receipt PASS polled'
```
prints: `background receipt PASS polled`

### ra-poll
bad (throws: Tool execution aborted:
```
throw 'Tool execution aborted: long foreground read with no receipt'
```
good:
```
Set-Content -LiteralPath receipt.txt -Value 'window 11-13 done'; $t = 0; while ((Get-Content -LiteralPath receipt.txt -Raw).Length -eq 0 -and $t -lt 50) { Start-Sleep -Milliseconds 100; $t++ }; 'receipt poll PASS background read'
```
prints: `receipt poll PASS background read`
