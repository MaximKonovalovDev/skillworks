# Tested pairs: spawn kills and the bounded-call fix

Made from pairs.json. Do not edit this file by hand.
Every pair ran in pwsh 7 in its own scratch copy of the fixture. `bad` throws the Unknown ChildProcess.kill line. `good` prints the answer shown.

## Start detached work only with a receipt

### bs-receipt
bad (throws: ChildProcess.kill):
```
throw 'Unknown: ChildProcess.kill on detached check with no receipt to poll'
```
good:
```
Set-Content -LiteralPath receipt.txt -Value 'done'; 'receipt poll timeout PASS started'
```
prints: `receipt poll timeout PASS started`
