# team

Team notes, one file per part of the product.

- `p1.md` pipeline, `p2.md` mcp, `p3.md` seeds, `p4.md` eval gate, `p5.md` shop.
- `workspace.md` is the shared workspace note. `coach.md` is the coach's note.
- `compact-log.md` logs every compaction of these notes.
- Score the parts: `python tools/part_score.py` (one line per part, from real data).
- Open first: `workspace.md`, then the part you work on.
