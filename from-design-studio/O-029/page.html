What is inside

pwsh-for-bash-writers

Fixes agents that type grep, head, tail, sed, awk or && into PowerShell 7 and watch the call fail.

real-browser-automation

A 30 KB Node script with no packages drives your installed Edge or Chrome over the DevTools protocol. Loopback only, three guard layers.

bevy-rust-ecs

Fixes old Bevy names that no longer exist. Every Bevy 0.19.1 name has its file and line.

Install

  1. Unzip the pack

    Unzip fleet-vol-1.zip. It holds skills/, zips/ and proof/.

  2. Copy the skills

    Copy the folders in skills/ to the skills folder of Claude Code or OpenCode.

  3. Check

    Ask the agent which skills it has, or run opencode debug skill --pure.
